# DSA 草稿的未完成工作与后续优化计划

本文件区分“已有可运行原型”与“只有设计、尚未实现”。当前面向动态图；不把静态图纳入本轮范围。

## 已有原型，继续收口

1. **SFA Grad 的分支选择**：已有 host tiling 补丁和历史完整梯度/单层耗时证据。下一步扩大短Q、TND碎片、H32/64/128、TopK及热点ID矩阵；按FP64参考和同分支重复波动评价，不能要求非确定性 dK 逐位相同。最后将有效规则提交算子仓，替代诊断变量。
2. **主Q独立流与main dKV延迟消费**：已有显式梯度gate、通信缓冲生命周期和独立stream代码。继续分析 Index K wait、Q RoPE 与 Q GEMM 梯度汇合；不能通过返回未完成的 receive tensor 伪造异步。确认临界rank收益后，再验证FSDP和重计算。
3. **worker partial-RoPE**：现成interleave算子可运行，但默认half需要重排且更慢。真正有价值的后续是原生half-prefix融合，直接写目标布局，并保留owner系数和舍入规则。
4. **非吸收式DSA**：已有FP64固定TopK输出和梯度参考。尚无可直接替换的非吸收式原生SFA/KL全链。需评估展开K/V的驻留、通信和重复投影，不能仅比较单个matmul。

## 尚未接通的功能

- **DSA分页Index K**：V4.1相关原型不等于DSA已经接入。需验证页表、逻辑前缀、文档局部TopK坐标与空任务；owner KL仍需要可微Index K，不能因选择侧no-grad省略学习路径。
- **Dense warmup均衡**：当前支持基本CP，均衡模式必须none。Dense KL处理全可见K，学生Q/weights和梯度路由是可微问题，不能套用仅返回整数TopK的选择调度。
- **padding Q的KL语义**：CE ignore label不会自动屏蔽KL。需要定义有效Q、文档padding、归一化、GAS与loss coefficient的一致接口，避免改了训练目标却只当性能优化。
- **TopK边界的长稳验证**：BF16 GEMM/LI分组不同会改变近阈值排序；owner-M补齐降低风险但不是任意训练轨迹逐位一致的证明。保留首次分叉输入并对照高精度分数。

## 调度、前后处理与容量

- 缓存完整区间pack计划、单次gather和worker单块cat旁路已在功能代码中。继续测冷规划、真正暴露的pack/恢复时间；接收落位/字段拆分/本地旁路与TopK恢复融合按场景比较，不假定融合必快。
- 进一步通信感知分配至少约束可见QK计算、worker Q容量、qr本地交集、发送热点和重复K物化。后置block交换使用有界候选/增量评分；只最小化通信字节会选出更慢方案。
- AG/A2AV自动阈值需联合通信量、连接数、pack/reduce成本和拓扑；不把通信量比值直接当耗时比值。
- 下一批CPU计划预取可与当前NPU计算重叠，但不同GAS micro-batch的文档长度不一定相同。当前重复几何缓存不是完整Trainer预取。
- 前向两批Q/TopK流水与main latent/RoPE K合包需要单独测试；同一communicator先发后等、独立stream的资源竞争都可能抵消收益。
- 1M、大CP需分别估算selection前缀、owner KL bank、dK输出和owner reduce临时内存，再做跨节点实测；单机CP8的时间不作为CP128预测值。

## 完成标准

先核对各实验的输入/输出、TopK语义和梯度路径，再测相同输入下的局部时间与整链临界时间。
有收益的默认候选需要必要的完整训练组合验证；失败或无收益的原型保留实验状态，不因进入Draft PR就改成默认。
